Web多屏互联陀螺仪赛车项目完整三套开发文档（纯网页版）
[README.md](README.md)
项目名称：Web 多屏互联陀螺仪赛车项目（纯网页 3D）
项目概述
本项目是一套 电脑大屏网页主机 + 手机 /iPad 网页控制器 的跨设备实时互联 3D 赛车系统，全程纯网页实现，无客户端、无引擎、无安装包、无本地编译。
整体运行逻辑：
电脑浏览器作为游戏主机大屏，负责 Three.js 全 3D 画面渲染、车辆物理模拟、赛道碰撞、游戏逻辑、房间服务管理。
手机 /iPad 浏览器访问同一个网页地址，切换为控制器模式，通过 6 位房间码 + 自定义密钥 绑定到大屏房间，利用设备陀螺仪与触控按钮完成转向、油门、刹车、手动挂挡操控。
所有游戏运算、3D 渲染、物理模拟全部运行在电脑大屏浏览器。
手机端仅负责传感器采集、UI 仪表盘展示、网络数据上传，不执行任何游戏逻辑与渲染。
核心互联规则：
1. 大屏创建房间 → 自动生成 6 位数字连接码
2. 大屏手动设置 自定义房间密钥
3. 手机输入「6 位码 + 密钥」完成配对连接
4. 单房间单控制器优先开发，多人多设备互联放置第六阶段迭代
运行与展示规范
1. 电脑大屏端：默认全屏沉浸式运行，展示完整实时 3D 赛车画面
2. 游戏正常运行时右上角仅显示帧率，无任何多余 UI，保证极致沉浸
3. 大屏开局后持续展示房间码、密钥与连接状态，待手机成功连接后再自动隐藏六位数字码与密钥
4. 内置隐藏开发者模式，快捷键开启后常驻全套调试信息
部署与发布优势
1. 纯网页项目，支持任意静态服务器部署、个人域名部署
2. 无上架费、无平台强制抽成、无需版号、无需客户端审核
3. 可直接作为网页游戏上架 [itch.io](itch.io) 等零门槛平台
4. 所有设备只需浏览器即可参与，无需安装、无需越狱、无需授权
硬件与开发环境清单
- 开发环境：Node.js、VSCode、TypeScript
- 游戏渲染：Three.js 纯 Web 3D 引擎
- 通信服务：原生 WebSocket 前后端实时通信
- 运行设备：
  - 主机端：任意电脑浏览器（全屏运行）
  - 控制器端：手机 /iPad 任意支持陀螺仪的现代浏览器
- 网络环境：公网 / 局域网均可，支持跨网段互联
核心功能清单
1. 操控系统：设备陀螺仪转向、触控油门、触控刹车、手动升降挡
2. 车辆物理系统：完整车速阻力、空气阻力、速度衰减、动态转向、漂移物理、五速手动变速箱
3. 视角系统分级开发：
  - 阶段一：仅第一人称车内视角
  - 阶段二：新增车尾跟随视角、上帝俯视视角、快捷键自由切换
4. 房间互联系统：6 位随机房间码、大屏自定义密钥、设备校验、断线自动保护
5. UI 展示系统：普通玩家沉浸模式 + 隐藏开发者调试模式
6. 仪表盘同步：手机端实时显示车速、挡位、漂移状态、网络连接状态
7. 游戏迭代内容：空白测试场地 → 标准赛道 → 差异化路面 → 手动变速箱 → 竞速计分 → 多人互联
项目架构简述
手机/iPad 浏览器（控制器、传感器采集、仪表盘UI）
        ↓ WebSocket 实时JSON通信
电脑浏览器（房间管理、3D渲染、车辆物理、赛道逻辑、游戏主控）
项目开发原则
1. 先核心逻辑、后美术场景；先单机稳定、后多人互联
2. 所有运算与渲染统一在大屏主机端，手机端只做输入输出
3. 模块化分层开发，每个阶段可独立运行、可独立验收
4. 优先保证操控手感、帧率稳定、低延迟通信，再迭代美术内容
项目交付产物
- 完整前端网页工程（HTML / CSS / TS / Three.js）
- Node.js WebSocket 后端服务
- 完整房间互联校验逻辑
- 全套开发文档（README / DEV / PLAN）
- 可直接部署上线的纯网页成品
